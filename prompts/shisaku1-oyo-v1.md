# 応用編の指示（版 1。2026-10-30）

MCP の道具（LINK_SCHEMA §14、DESIGN.md ADR-27）を使って、根拠を取り出し、推論を加えて、答弁・質問・広報文などを書かせるときの指示。共通の指示 v3（prompts/shisaku1-common-v3.md）の「---」より後に続けて置き、そのあとに依頼文（下の応1〜応6 の例を、場面に合わせて埋めたもの）を置く。2026-10-30 に、応2・応4・応5 を Opus 5.5 で試して、金額の単位の言い換えと広報ひのの扱いの2つを足した。全機能共通の規則（DESIGN.md ADR-9）による。変えるときは版を上げる。

---

## 応用編の進め方

次の3段で進め、出力もこの3段と「資料に無いこと」の4つに分けて書いてください。

1. 根拠を取り出す
   - MCP の道具で、依頼に関係する記載を取り出してください。overview → 関係する事項・施設の topic → 関係する一般質問の本文（council・speeches）→ 照合結果（issues）の順に確かめます
   - 取り出した記載を「根拠」の一覧にします。1件ごとに、番号（根1、根2…）、資料の日付、資料の名前、引用（原文のまま）、出典の url を書き、記録（未確認）か照合結果（未確認）のものには【未確認】と付けます
   - 同じ事柄で資料の日付の違う記載があれば、全部を資料の日付の順に並べ、いちばん新しいものに「いちばん新しい」と付けます
2. 推論する
   - 根拠から言えることを「推論」の一覧にします。1件ごとに、番号（推1、推2…）、推論の文、使った根拠の番号、確からしさ、確かめるには何が要るかを書きます
   - 確からしさは次の3つのどれかにします：「根拠に書いてある」「根拠から推せる」「根拠が足りない」
   - 根拠に無い事実を足さないでください。ほかの読み方ができるときは、それも別の推論として書いてください
   - 推論の文は、良し悪しや、どうすべきかの評価にしないでください（依頼文が案を求めているときの「提案：」は除く）
3. 書く
   - 依頼された成果物を書きます。文ごとに、使った根拠と推論の番号を［根1・推2］の形で付けます。決まり2の出典の url は、根拠の一覧の url で代えます
   - 推論を使った文は、成果物の中でも頭に「推論：」と書くか、推論であることが分かる書き方にします。広報文など町の名で出す文書には、推論を入れません
   - 町の資料と当局の答弁の言い回しは、原文のまま使います（決まり13）
   - 金額の単位を言い換える（千円を億円にするなど）ときは、資料の数字もそのまま並べて書き、言い換えたことが分かるようにします
   - 広報ひのの記載は、理由などの言い回しには使えますが、数字や時期の出典には使いません（決まり11）
4. 資料に無いこと・確かめること
   - 依頼に答えるのに要るのに、資料に無かったことと、確かめる先（担当課、議会の記録、計画の本文など）を挙げます

## 依頼文の例

- 応1 答弁案と、突っ込まれどころ（職員）：〔問いの中身〕について一般質問が出たと想定して、〔町長／課長〕の答弁の案を書いてください。あわせて、これまでの答弁や計画・予算の記載と並べたときに、再質問で問われそうな点を、根拠とあわせて挙げてください。
- 応2 答弁案の点検（職員）：次の答弁案を、これまでの答弁・計画・予算の記載と照らして点検してください。食い違い、言い換えで意味が変わったところ、根拠の無い言い切りを挙げ、直した案を示してください。〔答弁案を貼る〕
- 応3 一般質問の組み立て（議員）：〔テーマ〕について一般質問を組み立ててください。最初の問い、想定される答弁、答弁ごとの再質問の分かれ道を、根拠とあわせて示してください。まだ問われていない点があれば、根拠とあわせて示してください。
- 応4 影響の掘り下げ（職員・議員）：〔出来事。例：開園時期の見直し〕が、ほかの施設の再編・予算・工程・指定避難所などに与える影響を、資料から推せる範囲で整理してください。資料に書いてあることと、推せることと、根拠が足りないことを分けてください。評価や結論は書かないでください。
- 応5 広報文・説明資料（職員）：〔用途。例：広報ひのの記事、住民説明会の配布資料〕として、〔事柄〕の経緯といまの予定を〔字数〕字程度で書いてください。読み手は〔住民一般など〕です。数字と時期は計画・予算の記載から取り、未確認の記録は使わないでください。本文のあとに、読み手から出そうな問いと、それに答える根拠を挙げてください。
- 応6 想定問答（職員）：〔場。例：住民説明会、議会の委員会〕で〔事柄〕について出そうな問いを挙げ、問いごとに答えの案を書いてください。答えはこれまでの答弁・計画・予算の記載と食い違わないようにし、資料に無いことは「確認して後日お答えする」形にしてください。
