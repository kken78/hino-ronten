# 応用編の指示（版 3。2026-10-31）

MCP の道具（LINK_SCHEMA §14、DESIGN.md ADR-27）を使って、根拠を取り出し、推論を加えて、答弁・質問・広報文などを書かせるときの指示。共通の指示 v3（prompts/shisaku1-common-v3.md）の「---」より後に続けて置き、そのあとに依頼文（下の応1〜応6 の例を、場面に合わせて埋めたもの）を置く。2026-10-30 に、応2・応4・応5 を Opus 5.5 で試して、金額の単位の言い換えと広報ひのの扱いの2つを足した（版 1）。同じ日に、5つの依頼を Opus 5.5 と Sonnet 5.5 で試した結果から、読み上げ用の清書版、答弁の使い分け、つながりの決まりの範囲、広報ひのの引用の4つを足した（版 2）。2026-10-31 に、版 2 の指示で、会話を分けて Opus 5.5 と Sonnet 5.5 で確かめた結果（docs/eval-shisaku1.md §8）から、清書版の語尾と付け方、書き直しの経過を残さないこと、かぎかっこと字の幅の扱い、答弁の回と検討の段階の日付の読み方を足した（版 3）。全機能共通の規則（DESIGN.md ADR-9）による。変えるときは版を上げる。

## 応用編の進め方

次の3段で進め、出力もこの3段と「資料に無いこと」の4つに分けて書いてください。3段めの「書く」には、成果物の本文と、その清書版（読み上げ用）を入れます。

1. 根拠を取り出す
   - MCP の道具で、依頼に関係する記載を取り出してください。overview → 関係する事項・施設の topic → 関係する一般質問の本文（council・speeches）→ 照合結果（issues）の順に確かめます
   - 取り出した記載を「根拠」の一覧にします。1件ごとに、番号（根1、根2…）、資料の日付、資料の名前、引用（原文のまま）、出典の url を書き、記録（未確認）か照合結果（未確認）のものには【未確認】と付けます。答弁の記載には、道具が返す「回」（最初の問い・再質問1…。記録に無いときは「未記録」）と発言者も書きます。回を推して書かないでください
   - 同じ事柄で資料の日付の違う記載があれば、全部を資料の日付の順に並べ、いちばん新しいものに「いちばん新しい」と付けます
   - 検討の段階（政策の過程）の記載にある「期間」は、資料の日付ではありません。資料の日付は、記載の［ ］の日付か、検討の段階の記載では「資料：」のあとの（ ）の日付です。どちらも無いときは「資料の日付は記載に無い」と書きます
2. 推論する
   - 根拠から言えることを「推論」の一覧にします。1件ごとに、番号（推1、推2…）、推論の文、使った根拠の番号、確からしさ、確かめるには何が要るかを書きます
   - 確からしさは次の3つのどれかにします：「根拠に書いてある」「根拠から推せる」「根拠が足りない」
   - 根拠に無い事実を足さないでください。ほかの読み方ができるときは、それも別の推論として書いてください
   - 推論の文は、良し悪しや、どうすべきかの評価にしないでください（依頼文が案を求めているときの「提案：」は除く）
3. 書く
   - 依頼された成果物を書きます。文ごとに、使った根拠と推論の番号を［根1・推2］の形で付けます。決まり2の出典の url は、根拠の一覧の url で代えます
   - 推論を使った文は、成果物の中でも頭に「推論：」と書くか、推論であることが分かる書き方にします。広報文など町の名で出す文書には、推論を入れません
   - 町の資料と当局の答弁の言い回しは、原文のまま使います（決まり13）。ただし、答弁は下の「答弁の使い分け」によります
   - かぎかっこは、資料の文の引用と、資料にある正式な名前にだけ使います。自分で作った問い、見出し、答弁の型の名前（例：基本設計で精査していると答えた場合、のような分け方の名前）には使いません（決まり6）
   - 引用は、字の幅（全角・半角）、かっこ、句読点、数字も原文のまま写します（例：原文が「（当初：令和10年４月）」なら、「(当初:令和10年4月)」にしない）
   - 誤りに気づいたら、直した文だけを書きます。直した経過（「…ではなく」「誤りのため使いません」など）や、道具が返していない数字・url を、成果物にも根拠の一覧にも書きません（金額の単位の言い換えは、上の決まりのとおり資料の数字と並べて書きます）
   - 金額の単位を言い換える（千円を億円にするなど）ときは、資料の数字もそのまま並べて書き、言い換えたことが分かるようにします
   - 広報ひのの記載は、理由などの言い回しには使えますが、数字や時期の出典には使いません（決まり11）。かぎかっこで引くときも、時期や数字を含む部分は引きません。たとえば開園時期の見直しの理由を引くなら、「施設の確実な整備と安全性・品質確保を優先する観点から」までにし、時期は計画などの記載から、その資料の日付を添えて書きます
   - 本文のあとに「清書版（読み上げ用）」を付けます。本文から［根1・推2］などの番号、出典の url、引用のかぎかっこを外し、そのまま読み上げたり貼り付けたりできる文にします。言い回し・数字・時期・資料の日付は本文と同じにし、足したり省いたりしません。推論の文は、清書版でも推論であることが分かる言い方を残します
   - 清書版で引用のかぎかっこを外すと文がつながらないときは、引用の文の語尾だけを地の文に合わせて言い換えます（例：本文「「令和１１年度での開設を目指します。」としております」→ 清書版「令和１１年度での開設を目指すこととしております」）。語尾より前は言い換えません
   - 清書版は成果物ごとに付けます。1つの依頼で成果物が2つ以上あるときも、前の依頼に続けて頼まれたときも、省きません
4. 資料に無いこと・確かめること
   - 依頼に答えるのに要るのに、資料に無かったことと、確かめる先（担当課、議会の記録、計画の本文など）を挙げます

## 答弁の使い分け

- 回が「未記録」の答弁は、最初の答弁かどうかが記録から分からないものです。最初の答弁として扱わず、再質問以降の答弁と同じに扱います
- 時期・規模・費用・理由などを書くときは、町の資料（計画・構想・予算など）と、最初の答弁（記載の「回」が「最初の問い」のもの。町長・教育長が方針を答えたもの）を先に使います
- 再質問以降の答弁（課長などが口頭で答えたもの）は、町の資料と最初の答弁に無い点を補うときに使います。話し言葉をそのままかぎかっこで引かず、「〔資料の日付〕の答弁では、…との趣旨の答えがあった」の形で、趣旨と資料の日付を書きます。根拠の一覧には、いつもどおり原文のまま引きます
- 住民向けの文（広報文・説明資料・想定問答。応5・応6）では、口頭の答弁は趣旨だけを使い、資料の日付を付けます。町の資料と最初の答弁で言えることは、そちらで書きます
- 町の資料・最初の答弁と、再質問以降の答弁とで言い方が違うときは、どちらかに寄せず、両方を資料の日付とあわせて「推論」か「資料に無いこと・確かめること」に挙げます

## つながりの決まり（決まり9）の範囲

- 決まり9 の「つながりの記録に無いつながりは書かない」は、次の2つに当てます
  - 記載どうしの目的と手段、もとにした資料の関係
  - 根拠どうしの結び付き（ある記載が、別の記載の理由・前提・結果であると書くこと）
- 文と文をつなぐ言葉（「そのうえで」「また」「あわせて」など）には当てません。ただし、つなぐ言葉で上の2つの関係を言い表さないでください（例「〜のため、〜する」と書くと、目的と手段のつながりを言ったことになります）

## 依頼文の例

- 応1 答弁案と、突っ込まれどころ（職員）：〔問いの中身〕について一般質問が出たと想定して、〔町長／課長〕の答弁の案を書いてください。あわせて、これまでの答弁や計画・予算の記載と並べたときに、再質問で問われそうな点を、根拠とあわせて挙げてください。
- 応2 答弁案の点検（職員）：次の答弁案を、これまでの答弁・計画・予算の記載と照らして点検してください。食い違い、言い換えで意味が変わったところ、根拠の無い言い切りを挙げ、直した案を示してください。〔答弁案を貼る〕
- 応3 一般質問の組み立て（議員）：〔テーマ〕について一般質問を組み立ててください。最初の問い、想定される答弁、答弁ごとの再質問の分かれ道を、根拠とあわせて示してください。まだ問われていない点があれば、根拠とあわせて示してください。
- 応4 影響の掘り下げ（職員・議員）：〔出来事。例：開園時期の見直し〕が、ほかの施設の再編・予算・工程・指定避難所などに与える影響を、資料から推せる範囲で整理してください。資料に書いてあることと、推せることと、根拠が足りないことを分けてください。評価や結論は書かないでください。
- 応5 広報文・説明資料（職員）：〔用途。例：広報ひのの記事、住民説明会の配布資料〕として、〔事柄〕の経緯といまの予定を〔字数〕字程度で書いてください。読み手は〔住民一般など〕です。数字と時期は計画・予算の記載から取り、未確認の記録は使わないでください。本文のあとに、読み手から出そうな問いと、それに答える根拠を挙げてください。
- 応6 想定問答（職員）：〔場。例：住民説明会、議会の委員会〕で〔事柄〕について出そうな問いを挙げ、問いごとに答えの案を書いてください。答えはこれまでの答弁・計画・予算の記載と食い違わないようにし、資料に無いことは「確認して後日お答えする」形にしてください。
