# ほかの3題材の調べ：幼保と同じ形か、別の論点がありそうか（2026-10-25）

題材は ADR-13 の4つ（幼児教育・保育施設の再編、高齢者福祉・介護、公共施設の再編、地域のあり方・自治会活動）。幼保以外の3つについて、計画・会議録・広報ひの・hino-town-docs を見て、いまのデータの形で足りるかを調べた。

使った版：hino-council-search 1af9baa（2021年4月〜2026年5月の会議録）、shiga-hino-plans 30bfb26、hino-town-docs 267b0f8。会議録の引用は sid を付けた。

## 1. 題材ごとの姿

幼保と違うところ：

- 過程が1回きりではなく、期ごとに繰り返す（第8期 → 評価 → 第9期 → 評価 → 第10期）。第10期（令和9〜11年度）の計画は、今年度（令和8年度）に作られる
- 計画が、前の期の達成度を町自身の評価として持っている。執行管理（柱 B）の材料になる
- 懇話会のような会の議事録は、hino-town-docs に無い（策定の会があるかどうかも、まだ調べていない）

幼保と似ているところ：

- 「地域包括ケアシステムの深化・推進」「地域共生社会」など、国の考え方を町の計画に取り込んだ言葉があり、資料ごとに置かれ方を追う形（幼保の「適正な集団規模」と同じ）が使える
- 「公民館単位での協議体の設置数【総合計画共通】」（目標4、実績1、未達成（変化なし））のように、総合計画と共通の指標があり、地域のあり方の題材にもつながる

幼保と違うところ：

- 主語が施設になる。1つの施設が、いくつもの題材にまたがる。例：公民館は、社会教育の施設、避難所（2026年3月の町長答弁「地区全体の取りまとめ拠点」、sp:0000008942_20260309_0015）、地域づくりの拠点、介護の協議体の単位。幼稚園は、休園のあと、子育て支援施設や学童保育所に転用される（再編整備計画）
- いまのデータには、施設を指すキーが無い
- 説明の場が、広報ひのではなく、計画と議会に寄っている

幼保にもかかわる発見：

- 子育て支援施設の個別施設計画（令和3年12月）の基本方針に、すでに「幼稚園や保育所の再編より認定こども園化を進め」とあった（2026年3月の子ども支援課長の答弁、sp:0000008942_20260309_0197）。懇話会（2022年7月から）より前の資料で、幼保の過程の始まりにかかわる。この計画の原典は、まだ取り込んでいない

幼保と違うところ：

- 計画が無く、始まりが公約。計画への言及の台帳は使えない（2026-10-21 の試作0でも0件）
- 町だけでなく、自治会や協議会など、町の外の組織が主な担い手になる。いまのデータには組織のキーが無い
- 7つの地区（公民館の単位）ごとに状況が違う。いまの記録には地区の欄が無い
- 資料が、町のホームページのページ（アンケートの結果）や YouTube の動画になっている。hino-town-docs は PDF だけを扱っている

## 2. 4つの題材に共通して見えたこと

- **議案の質疑が記録の外にある**：やりとりの記録（§15.2）は一般質問だけを扱う。会議録の質疑のうち、幼保にかかわる語を含むまとまりは57（2021年4月以降）。2026年3月5日の令和8年度予算（議第115号）の質疑だけでも、幼保にかかわるものが5人分ある。予算審議はプロジェクトマネジメントの最大の節目なので、幼保でも、e008 の3枚に要る
- **1つの記載・施設・言葉が、題材をまたぐ**：公民館、人手不足（介護・障がい福祉・保育）、協議体、子育て支援施設の個別施設計画。いまは、テーマの定義も記録の台帳も theme の列で分けているので、同じ記載を題材ごとに書くことになる
- **原典が取り込めていない資料がある**：施設ごとの計画、アンケートの結果のページ、動画、会の議事録（介護の策定の会など）

## 3. データの形への当てはめ

| 見えたこと | いまの形で足りるか | 当てはまる題材 | 直すとしたら |
| --- | --- | --- | --- |
| 言葉の置かれ方の経緯（「適正な集団規模」型） | about の列と point の直し（今回入れる）で足りる | 4つとも | — |
| 予定の変更と理由 | 事柄の記録で足りる | 地域（自治活性化推進員の配置の見送り）、幼保（開園時期） | — |
| 同じ答弁の繰り返し | やりとりの記録で足りる（問いの行の引用でわかる） | 地域 | — |
| 議案の質疑・討論 | 足りない | 4つとも（幼保の予算審議を含む） | やりとりの記録で質疑も扱うか、別の台帳にする |
| 期ごとに繰り返す過程 | 足りない（過程の記録は1本の時の並び） | 介護（ほかの法定計画も同じ） | 過程の記録に期の列を足すか、期ごとに段階を分ける |
| 計画の中の前の期の評価 | 計画の記載として引ける | 介護 | 画面の出し方（町の評価として、そのまま引く）を決める |
| 施設 | 足りない（キーが無い） | 公共施設、幼保、地域、介護 | 施設のキー（GIF のコアデータモデルの「施設」に当たる） |
| 町の外の組織 | 足りない（キーが無い） | 地域、介護 | 組織のキー（Popolo の Organization に当たる） |
| 地区 | 足りない | 地域、介護（日常生活圏域）、公共施設（地区公民館） | 記録に地区の欄を足すか、地区のキー |
| 題材をまたぐ記載 | 書けるが重なる | 4つとも | 記載をテーマから離して持ち、テーマの定義で選ぶ形 |
| PDF でない資料（ページ・動画） | 足りない | 地域 | hino-town-docs の扱う範囲を決める（判断事項18） |
| 計画の下の計画（個別施設計画） | 足りない（原典が無い） | 公共施設、幼保 | hino-town-docs か shiga-hino-plans に取り込む |

## 4. 決めたこと（2026-10-25）

- 今回は、幼保（e008）の3枚に要る直しだけを入れる。構造にしていない記載の about の列、やりとりの記録の point の直し、問い4問の追加、テーマの定義の記載・資料の5行（DESIGN.md ADR-21）
- 議案の質疑は、別の台帳（records/shitsugi.tsv。LINK_SCHEMA §15.7）で記録する。e008 で扱う質疑は、議第115号（令和8年度予算）と議第25号（令和7年度予算）の質疑から、S3 の前に選ぶ
- 子育て支援施設の個別施設計画（令和3年12月）は、町のサイトの計画の一覧、子育て支援の事業計画の一覧、公共施設等総合管理計画のページで見つからなかった。原典は引かず、その中身を述べた答弁（sp:0000008942_20260309_0197）を資料として記録する
- 子育て支援の事業計画の一覧に、日野町認定こども園整備基本構想（2026-10-23 公開。2025年12月の一般質問で「この８月にまとめられた」とされたもの）があった。hino-town-docs に取り込む
- 施設・組織・地区のキー、期ごとに繰り返す過程、題材をまたぐ記載、PDF でない資料と計画の下の計画は、2つめの題材に入る前の見直しの時点（docs/kiban-2026-10-25.md §4.2）で決める。DESIGN.md §6 の判断事項20〜23 に書いた
