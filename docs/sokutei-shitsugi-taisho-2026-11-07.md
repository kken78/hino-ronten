1. B の照らし先。当初予算と同じまとまり（令和6年3月7日と令和7年3月7日の8まとまり、35発言）では、事業名の出た発言23のうち、○の行と名前がすべて一致したものは1、一致が無いもの15。これらの発言の多くは当初予算の事業を聞いている。行に「当初か補正か」を書く列が無いので、○の行に無い事業名がこのまとまりに偏る。補正だけのまとまり（43まとまり、184発言）では、事業名の出た発言74のうち47がすべて一致、18が一致なし。B の一致しなかった名前の数（発言×事業名）79 のうち50が当初予算と同じまとまりにある。
2. 年度。附表の一致は議案の年度の附表で見た。令和6年3月の補正予算（令和5年度第8号）と同じまとまりで当初予算（令和6年度）の事業を聞いている発言は、令和5年度の附表で見ているので一致しないものがある。次の年度の附表で見れば一致する名前があるが、数えていない。
3. 款の名前だけの発言。款の名前（例「土木費」「民生費」）だけでも款に数えた。「款・項・目・節」の番号つきの発言は B で31。予算書とつなぐ候補としては、番号つきの31を見るのがよいと思う。
4. ページ。資料名を言わないページ（59か所）を予算書のページに入れた。補正予算書か当初予算書か、事項別明細書かは分けていない。同じ答えの中で、問いのページをくり返すものもある。
5. 施設・場所の一覧は、発言を読んで足した名前を含む（一覧に無い施設は数えていない）。地区の語は、固有の名前のあるもの（佐久良地区・北山地区 など）だけを入れ、「各地区」などは入れていない。
