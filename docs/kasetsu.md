# 仮説の台帳

設計の見立て（H）と、それに依る決定（D）を分けて書く。行は消さない。状態が変わったら、経緯に日付・状態・根拠を足す。状態は、仮説・合った・合わなかった・直した、の4つ。深さは、キー・判定した列・列の有無・道具・見せ方、のどれか（深いほど直す手間が大きい）。

書き方の決まり：

- 見立ては、何についての見立てか（町の資料・議会・使う人・道具）を書く。出どころは、どの題材・どの確かめ・誰の判断から来たかを書く
- 例は、台帳の行のキーと公開の資料で書く。庁内の資料や会議の存否や性質を書かない
- 検査の信号は、道具が出す数字と、止める値。値は、測ってから決める
- 下書きと見直しをした生成AIのモデルの名前と日付を、経緯に書く

## H-1 計画・予算・議会の議論は、実施計画の事業に集まる

- 何についてか：町の資料と議会
- 出どころ：幼保（e008）。docs/review-2026-10-21.md §7.6 の「最初の単位は、実施計画の事業とする」
- 当てはまる範囲：1つの事業に計画・予算・議会の議論が集まる題材。幼保はそうだった
- 依っている決定：D-1
- 合っている例：幼保。records/kotogara.tsv の hoiku の55行のうち、新こども園の事柄（面積・定員・用地・整備費用と財源・開園時期）は e008 に対応づく
- 合っていない例：介護。第9期の介護保険料・介護給付費準備基金・地域密着型サービスの事業所の整備・要介護認定率は介護保険特別会計の側で、当たる事業が実施計画に無い。「地域支援事業から重層的支援体制整備事業への移管」は e110・e109・e093 にまたがる（ref/themes.tsv の kaigo の事柄の行）。records/yaritori.tsv の iq:0000008691_20251212_0210 の71行のうち25行が点（空）
- 外れたと言える条件：確定した事柄・記載のうち、どの事業にも対応づかない行が、その題材で多数になる（信号 (a)・(c)。値は測ってから）
- ほかの見立て：議論は「点」に集まり、事業・期・会計・施設・地区は点をまとめる見方である（H-2）
- 確かめ方と時点：題材の形の確かめ（テーマの定義の前）
- 深さ：道具の引数・出力のファイル名・判定した列（kotogara の program）
- 外れたときの手間：ADR-31 の D-1 の直し。幼保の program 55行は themes.tsv の views に写すだけで、判定のやり直しは無い
- 経緯：2026-10-24 仮説（ADR-15）。2026-11-04 合わなかった（介護 K3e の前。判定シート K3c、Opus 5.5 と Fable 5.1 での確かめ）。2026-11-04 直した（ADR-31。K4 で道具とデータを移し替えた。dcb2b38）。信号の最初の値：(a) 575 行（うち記載の点が515。幼保の記載に views を書いていないため）、(c) 幼保 0.11。記載の点の views の方針を決めるまで、この2つの信号では H-1 の当否を言えない。(b) は介護の2問と幼保の1問が 0.2 を超え、ほかは 0.07 以下（検査 Fable 5.1、2026-11-04）。2026-11-05 介護 K3e の結果（下書き Opus 5.5、見直し Opus 5.5・Fable 5.1）：確定した事柄73・つながり11・記載80。信号 (c) 介護 0.13（164行のうち21行）。中心の見方は、事業（e110）より期の計画（plan:kaigo9）に寄る（事柄12のうち plan:kaigo9 に出るのが5、e110 を含むのが1）。H-1 は介護では合わず、点が事業の外（特別会計・期の計画）に集まることが数でも見えた。止める値は、記載の点の views の方針のあとに決める

## H-2 人の推論の単位は「点」で、点は時を越えて続く

- 何についてか：使う人（職員の答弁の準備、議員の質問の準備）
- 出どころ：docs/review-2026-10-21.md §7.7（同じ点が会議をまたいで問われる。新こども園の面積は2024年12月から2025年3月までに3回）。§13.2 の論点の候補の比べ方は、どれも同じ点の行どうしを比べる
- 当てはまる範囲：U1〜U3（質問と答弁の準備、想定問答）。U4〜U6（経緯の検証・研修・住民向けの説明）で成り立つかは未確認
- 依っている決定：D-2・D-3
- 合っている例：幼保の「新こども園の定員」。2024年12月の「基本構想策定の中で決めていきたい」から2025年12月の「285」まで、yaritori と kotogara の point でつながる
- 合っていない例：まだ無い
- 外れたと言える条件：職員・議員が、点をまたいだ見方（例 1つの会議の答弁の全体、1つの計画の全体）を主に使い、点ごとの並びを使わない（K6・公共施設と地域のあり方で見せたときの反応）
- ほかの見立て：推論の単位は資料（1つの計画、1回の会議）である
- 確かめ方と時点：職員・議員に見せる工程（K6 と、ほかの2題材の同じ工程）
- 深さ：キー（point が台帳をつなぐ列）
- 外れたときの手間：大きい。台帳のつなぎ方そのものを変えることになる
- 経緯：2026-10-24 仮説（ADR-16・ADR-19）。2026-11-04 ADR-31 で中心の単位にした（まだ使う人で確かめていない）

## H-3 行ごとの人の判定は、この段階の誤りを拾う

- 何についてか：道具と作業の進め方
- 出どころ：ADR-2・不変の制約11（2026-10-10）
- 当てはまる範囲：記録の台帳の下書きの判定
- 依っている決定：D-4
- 合っている例：幼保の S3（判定シート2b などで、引用の切り方・問いの前提の行の足し方を依頼者が直した）
- 合っていない例：介護の K3a〜K3d。記録の行321と記録しない文203で、直しが0行（2026-11-04）
- 外れたと言える条件：判定シートで直しが0行の状態が続く。または、判定にかかる時間が見込みを超える（docs/kiban-2026-10-25.md §4.1 の3）
- ほかの見立て：下書きの質は、道具の検査と、別の文脈の生成AIの見直しで足りる。人の判定は、意味の分かれ目と抜き取りに使うほうがよい（D-4）
- 確かめ方と時点：抜き取りの判定で誤りが出る割合（判定シートごと）。モデルが変わったとき
- 深さ：進め方（文書）
- 外れたときの手間：小さい。行ごとの判定に戻す
- 経緯：2026-10-10 仮説（ADR-2）。2026-10-25〜27 合った（幼保 S3）。2026-11-04 合わなかった（介護 K3a〜d。下書き Opus 5.5）。2026-11-04 直した（ADR-31 の3）

## H-4 期は点の名前で表せる（「第9期の介護保険料」のように）

- 何についてか：道具（台帳の形）
- 出どころ：介護 K2（2026-11-04）。事柄の記録には cycle の列が無く、過程の記録にだけ足した（ADR-30）
- 当てはまる範囲：期ごとに作り直す計画の題材（介護。ほかの法定計画も）
- 依っている決定：D-2（見方の種類に「期の計画」を含める）
- 合っている例：まだ無い（第10期の行がまだ無い）
- 合っていない例：まだ無い
- 外れたと言える条件：第10期の計画ができたとき、「第9期の介護保険料」と「第10期の介護保険料」が別の点になり、予定の変更の比べ方（§13.2）で比べられない
- ほかの見立て：期は見方のキー（plan:kaigo9・plan:kaigo10）で持ち、点の名前から期を外す（「介護保険料」）
- 確かめ方と時点：第10期の計画の取り込みのとき（令和9年度）。それより前に、介護の形の確かめ（K3e0）で、点の名前から期を外せるかを見る
- 深さ：判定した列（point の名前）
- 外れたときの手間：中くらい。点の名前の付け替え（themes.tsv と台帳の point の置換）。判定のやり直しは無い
- 経緯：2026-11-04 仮説（K2 の判定シート K2b）

## H-5 問いのロジックモデルの区分（stage）は、行ごとに人が付ける価値がある

- 何についてか：使う人と道具
- 出どころ：ADR-16（問いを区分で分けると、成果を問うものが少ないと分かった。docs/review-2026-10-21.md §7.7）
- 当てはまる範囲：やりとりの記録・質疑の記録の問いの行
- 依っている決定：D-5
- 合っている例：幼保の「問われていない区分」（§13.2）が画面と MCP に出る
- 合っていない例：まだ無い
- 外れたと言える条件：職員・議員が「問われていない区分」を使わない。または、二者の生成AIの区分の一致が低く、人の判定の手間に見合わない
- ほかの見立て：区分は、ADR-18 の記載と同じく、使う人が自分で置く（台帳に持たない）
- 確かめ方と時点：K6 の反応。抜き取りの判定での区分の一致の割合
- 深さ：判定した列（stage）
- 外れたときの手間：小さい。列を残したまま使わなくすればよい
- 経緯：2026-10-24 仮説（ADR-16）。2026-11-04 ADR-18 との非対称を記録（読み直しの指摘）

## H-6 この設計は、ほかの自治体にも使える

- 何についてか：設計の全体
- 出どころ：docs/review-2026-10-21.md §7.8（依頼者。コンテキストをどこに残すかという観点で、ほかの自治体にも示唆を与えるものになるとよい）
- 当てはまる範囲：日野町の4題材のあと
- 依っている決定：D-2（見方の種類を足せる形）、D-6
- 合っている例：まだ無い
- 合っていない例：まだ無い
- 外れたと言える条件：別の自治体の資料で、キーの形（LINK_SCHEMA §2）か見方の種類を変えないと記録が書けない
- ほかの見立て：自治体ごとに資料の形が違いすぎて、キーと見方を自治体ごとに決める必要がある
- 確かめ方と時点：4題材のあと。それまでは、日野町に固有の名前（計画の id、事業の key）を、キーの形の決まりと分けて書いておく
- 深さ：キー
- 外れたときの手間：大きい
- 経緯：2026-10-24 仮説。2026-11-04 条件ではなく仮説として置くことにした
