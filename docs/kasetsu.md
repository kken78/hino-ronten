# 仮説の台帳

設計の見立て（H）と、それに依る決定（D）を分けて書く。行は消さない。状態が変わったら、経緯に日付・状態・根拠を足す。状態は、仮説・合った・合わなかった・直した、の4つ。深さは、キー・判定した列・列の有無・道具・見せ方、のどれか（深いほど直す手間が大きい）。

書き方の決まり：

- 見立ては、何についての見立てか（町の資料・議会・使う人・道具）を書く。出どころは、どの題材・どの確かめ・誰の判断から来たかを書く
- 例は、台帳の行のキーと公開の資料で書く。庁内の資料や会議の存否や性質を書かない
- 検査の信号は、道具が出す数字と、止める値。値は、測ってから決める
- 下書きと見直しをした生成AIのモデルの名前と日付を、経緯に書く

## H-1 計画・予算・議会の議論は、実施計画の事業に集まる

- 何についてか：町の資料と議会
- 出どころ：幼保（e008）。docs/review-2026-10-21.md §7.6 の「最初の単位は、実施計画の事業とする」
- 当てはまる範囲：1つの事業に計画・予算・議会の議論が集まる題材。幼保はそうだった
- 依っている決定：D-1
- 合っている例：幼保。records/kotogara.tsv の hoiku の55行のうち、新こども園の事柄（面積・定員・用地・整備費用と財源・開園時期）は e008 に対応づく
- 合っていない例：介護。第9期の介護保険料・介護給付費準備基金・地域密着型サービスの事業所の整備・要介護認定率は介護保険特別会計の側で、当たる事業が実施計画に無い。「地域支援事業から重層的支援体制整備事業への移管」は e110・e109・e093 にまたがる（ref/themes.tsv の kaigo の事柄の行）。records/yaritori.tsv の iq:0000008691_20251212_0210 の71行のうち25行が点（空）
- 外れたと言える条件：確定した事柄・記載のうち、どの事業にも対応づかない行が、その題材で多数になる（信号 (a)・(c)。値は測ってから）
- ほかの見立て：議論は「点」に集まり、事業・期・会計・施設・地区は点をまとめる見方である（H-2）
- 確かめ方と時点：題材の形の確かめ（テーマの定義の前）
- 深さ：道具の引数・出力のファイル名・判定した列（kotogara の program）
- 外れたときの手間：ADR-31 の D-1 の直し。幼保の program 55行は themes.tsv の views に写すだけで、判定のやり直しは無い
- 経緯：2026-10-24 仮説（ADR-15）。2026-11-04 合わなかった（介護 K3e の前。判定シート K3c、Opus 5.5 と Fable 5.1 での確かめ）。2026-11-04 直した（ADR-31。K4 で道具とデータを移し替えた。dcb2b38）。信号の最初の値：(a) 575 行（うち記載の点が515。幼保の記載に views を書いていないため）、(c) 幼保 0.11。記載の点の views の方針を決めるまで、この2つの信号では H-1 の当否を言えない。(b) は介護の2問と幼保の1問が 0.2 を超え、ほかは 0.07 以下（検査 Fable 5.1、2026-11-04）。2026-11-05 介護 K3e の結果（下書き Opus 5.5、見直し Opus 5.5・Fable 5.1）：確定した事柄73・つながり11・記載80。信号 (c) 介護 0.13（164行のうち21行）。中心の見方は、事業（e110）より期の計画（plan:kaigo9）に寄る（事柄12のうち plan:kaigo9 に出るのが5、e110 を含むのが1）。H-1 は介護では合わず、点が事業の外（特別会計・期の計画）に集まることが数でも見えた。止める値は、記載の点の views の方針のあとに決める

## H-2 人の推論の単位は「点」で、点は時を越えて続く

- 何についてか：使う人（職員の答弁の準備、議員の質問の準備）
- 出どころ：docs/review-2026-10-21.md §7.7（同じ点が会議をまたいで問われる。新こども園の面積は2024年12月から2025年3月までに3回）。§13.2 の論点の候補の比べ方は、どれも同じ点の行どうしを比べる
- 当てはまる範囲：U1〜U3（質問と答弁の準備、想定問答）。U4〜U6（経緯の検証・研修・住民向けの説明）で成り立つかは未確認
- 依っている決定：D-2・D-3
- 合っている例：幼保の「新こども園の定員」。2024年12月の「基本構想策定の中で決めていきたい」から2025年12月の「285」まで、yaritori と kotogara の point でつながる
- 合っていない例：まだ無い
- 外れたと言える条件：職員・議員が、点をまたいだ見方（例 1つの会議の答弁の全体、1つの計画の全体）を主に使い、点ごとの並びを使わない（K6・公共施設と地域のあり方で見せたときの反応）
- ほかの見立て：推論の単位は資料（1つの計画、1回の会議）である
- 確かめ方と時点：職員・議員に見せる工程（K6 と、ほかの2題材の同じ工程）
- 深さ：キー（point が台帳をつなぐ列）
- 外れたときの手間：大きい。台帳のつなぎ方そのものを変えることになる
- 経緯：2026-10-24 仮説（ADR-16・ADR-19）。2026-11-04 ADR-31 で中心の単位にした（まだ使う人で確かめていない）

## H-3 行ごとの人の判定は、この段階の誤りを拾う

- 何についてか：道具と作業の進め方
- 出どころ：ADR-2・不変の制約11（2026-10-10）
- 当てはまる範囲：記録の台帳の下書きの判定
- 依っている決定：D-4
- 合っている例：幼保の S3（判定シート2b などで、引用の切り方・問いの前提の行の足し方を依頼者が直した）
- 合っていない例：介護の K3a〜K3d。記録の行321と記録しない文203で、直しが0行（2026-11-04）
- 外れたと言える条件：判定シートで直しが0行の状態が続く。または、判定にかかる時間が見込みを超える（docs/kiban-2026-10-25.md §4.1 の3）
- ほかの見立て：下書きの質は、道具の検査と、別の文脈の生成AIの見直しで足りる。人の判定は、意味の分かれ目と抜き取りに使うほうがよい（D-4）
- 確かめ方と時点：抜き取りの判定で誤りが出る割合（判定シートごと）。モデルが変わったとき
- 深さ：進め方（文書）
- 外れたときの手間：小さい。行ごとの判定に戻す
- 経緯：2026-10-10 仮説（ADR-2）。2026-10-25〜27 合った（幼保 S3）。2026-11-04 合わなかった（介護 K3a〜d。下書き Opus 5.5）。2026-11-04 直した（ADR-31 の3）

## H-4 期は点の名前で表せる（「第9期の介護保険料」のように）

- 何についてか：道具（台帳の形）
- 出どころ：介護 K2（2026-11-04）。事柄の記録には cycle の列が無く、過程の記録にだけ足した（ADR-30）
- 当てはまる範囲：期ごとに作り直す計画の題材（介護。ほかの法定計画も）
- 依っている決定：D-2（見方の種類に「期の計画」を含める）
- 合っている例：まだ無い（第10期の行がまだ無い）
- 合っていない例：まだ無い
- 外れたと言える条件：第10期の計画ができたとき、「第9期の介護保険料」と「第10期の介護保険料」が別の点になり、予定の変更の比べ方（§13.2）で比べられない
- ほかの見立て：期は見方のキー（plan:kaigo9・plan:kaigo10）で持ち、点の名前から期を外す（「介護保険料」）
- 確かめ方と時点：第10期の計画の取り込みのとき（令和9年度）。それより前に、介護の形の確かめ（K3e0）で、点の名前から期を外せるかを見る
- 深さ：判定した列（point の名前）
- 外れたときの手間：中くらい。点の名前の付け替え（themes.tsv と台帳の point の置換）。判定のやり直しは無い
- 経緯：2026-11-04 仮説（K2 の判定シート K2b）

## H-5 問いのロジックモデルの区分（stage）は、行ごとに人が付ける価値がある

- 何についてか：使う人と道具

- 当てはまる範囲：やりとりの記録・質疑の記録の問いの行
- 依っている決定：D-5

- 合っていない例：まだ無い

- 深さ：判定した列（stage）

## H-10 補正予算の行は、附表の事業との対応でなく、提案理由の文とのつながりで記録すると、人が判定できる

- 合っている例：(1) 監査委員の資料の記録の形を2日で3回直した。どれも資料の中から構造を作った。様式の欄に合わせた表（hino-town-docs の作業で3回作り直した。財政援助団体等の監査の報告の「監査対象課等」の欄）→ 文ごとに切って事項（論点）に対応づけた下書き（414e690。根拠の数の給付費の計画比率を落とした）→ 意見の項目（当時の呼び方では筋）を論点ごとに束ねた形（ADR-36。19の項目のうち12が2つ以上の論点にまたがり、論点で切れた）。(2) 第9期 高齢者福祉計画・介護保険事業計画 第5章の「介護保険料の計算の流れ」の図（pt:kaigo9/honpen/49）の要素に事項（論点）を対応づけると、監査委員の資料が毎年記しているのは、図の要素のうち認定率（要介護認定率）と給付費（給付費の計画と実績）の2つで、サービス別給付費単価の設定と地域支援事業費の推計には、事項も記録も無いことが分かった（見本のページ、2026-11-14）。資料の中の項目からは、この「記していない要素」は出てこない。(3) 財政援助団体等の監査の報告13本は、様式の欄の書き方がそろわないが、どれも地方自治法第199条第7項にもとづく、町と相手の間のお金の監査である（kansa-r4-16・kansa-r6-17・kansa-r7-20）
- 合っていない例：まだ無い
- 外れたと言える条件：資料の外に出典のある枠組みが見つからない題材が続く。または、枠組みの要素に対応づけた事項と記録が、資料の中の項目で読むときより使う人に読まれない
- ほかの見立て：根拠規定は、資料が作られる理由として書いておけば足りる。構造は資料の中の項目から作ってよい
- 確かめ方と時点：H-18 と同じ（介護の画面を見せるとき（K6）、次の題材の形の確かめ）。新しい種類の資料を記録するときの形の確かめで、根拠規定と枠組みを先に読む
- 深さ：見せ方と列の有無（枠組みは参照表と見方、項目は列 suji。DESIGN.md ADR-37）
- 外れたときの手間：中くらい。枠組みの参照表と見方を使わなくするだけで、記録の行は直さない
- 経緯：2026-11-13 仮説（元の題「資料の種類ごとの根拠規定が、記録の単位を決める。形の確かめに「根拠規定と、それが決める単位」を足すと、様式に引きずられた括りを避けられる」。下書き：Fable 5.2。文書：Opus 5.5。hino-zaisei の画面「決算と監査」の材料づくりから出た。元の出どころ：依頼者の指摘（2026-11-12）。財政援助団体等の監査の報告で文字の層のある13本は、どれも冒頭に地方自治法第199条第7項にもとづくと書いてあり、対象のお金の種類は補助金・負担金・指定管理料・委託料に分かれる。元の外れたと言える条件：根拠規定を確かめても、単位が様式の欄と変わらない題材が続く。元の深さ：見せ方より浅い（形の確かめで確かめる項目の文を足すだけ））。2026-11-14 書き直した（依頼者の指摘と点検の報告による。根拠規定が記録の単位を決めるのではなく、根拠規定・制度・その分野の流れが資料の外の枠になり、資料の中の筋は述べ方として残す、という形に広げた（「枠」「筋」「述べ方」は当時の呼び方）。DESIGN.md ADR-37。下書き Fable 5.2、文書 Opus 5.5）。2026-11-14 言い方を改めた（枠 → 枠組み、筋 → 項目、述べ方 → 記載。DESIGN.md ADR-37 の経過。中身は変えていない）

## H-17 監査委員の要望に対する町の応答は、決算審査の意見書については議会の決算の審議に、定期監査については措置の通知に現れる。前者は質疑の対象の字で意見書の箇所を指せば足り、後者は資料が見当たらないので、記載の台帳の列で足りる

- 何についてか：町の資料と議会
- 出どころ：DESIGN.md ADR-36 の位置づけの確かめ（2026-11-14。決算審査の意見書は地方自治法233条で町長あてに出て決算の議案に付き、意見への応答を通知・公表する定めは無い。定期監査の結果と勧告には措置の通知と公表（199条14項・15項）があるが、日野町の措置の公表は、調べた範囲では見当たらない）と、依頼者が17のやりとりを意見書と見比べた結果（H-13）
- 当てはまる範囲：監査委員の資料（決算審査の意見書、定期監査の報告。財政援助団体等の監査は試していない）の要望と、それへの町の応答
- 依っている決定：D-13（DESIGN.md ADR-36 の6）
- 合っている例：決算審査の意見書。令和3〜6年度の決算の議案の質疑の日に意見書に触れたやりとり17のうち14を、依頼者が意見書の箇所に当てた（H-13 の経緯）。意見書への応答は、議会の決算の審議の質疑と答弁に現れている
- 合っていない例：まだ無い
- 外れたと言える条件：措置の資料が見つかる。1つの筋が2つ以上の点にまたがって、同じ筋と読めなくなる
- ほかの見立て：要望と町の応答（措置・答弁）を結ぶ台帳（議会のやりとりの型）が要る
- 確かめ方と時点：介護の筋を記録して画面で読んだとき。日野町監査基準を取り込んだとき
- 深さ：列の有無（外れたときは新しい台帳（議会のやりとりの型）になる）
- 外れたときの手間：大きい。LINK_SCHEMA の改定と道具の追加になる
- 経緯：2026-11-14 仮説（下書き：Fable 5.2。文書：Opus 5.5。DESIGN.md ADR-36 の位置づけの確かめから出た）。2026-11-14 合わなかった（外れたと言える条件の2つめ「1つの筋が2つ以上の点にまたがって、同じ筋と読めなくなる」に当たった。監査委員の資料の19の筋のうち12が2つ以上の点にまたがり、同じ点・同じ資料で束ねる形（ADR-36 の決定3）では同じ筋と読めなかった。点検の報告 tenken-2026-11-14.md の C.1。措置の資料が見つからないこと（前半）は変わらない。見直した決定：D-13 の「同じ点の名前で書く」の部分を、DESIGN.md ADR-37（D-14）で改めた。筋は列 suji で束ね、位置づけは ref/shiryo.tsv に移した。文書 Opus 5.5）。この見立ての「筋」は当時の呼び方で、いまは「項目」（監査委員の資料では意見の項目）と呼ぶ（2026-11-14）

## H-18 出典のある枠組みの要素に事項（論点）を対応づけると、資料が記している要素と記していない要素が分かり、埋もれた論点を探す手がかりになる。資料の中の項目は、番号の列で束ねれば、論点をまたいでも切らずに読める

- 何についてか：使う人（職員の答弁の準備、議員の質問の準備）と、記録の設計
- 出どころ：依頼者の指摘（2026-11-14）と、見本のページでの確かめ（2026-11-14。依頼者が「よくなった」とした）。点検の報告 tenken-2026-11-14.md の C（形2）
- 当てはまる範囲：出典のある枠組み（計画の図・制度の流れ・根拠規定）がある題材。まず介護（枠組み：介護保険料の計算の流れ、pt:kaigo9/honpen/49）と、監査委員の資料の項目
- 依っている決定：D-14（DESIGN.md ADR-37）
- 合っている例：介護。枠組みの要素10のうち、事項が対応づくのは5（要介護認定率・給付費の計画と実績・介護保険料の収納・介護給付費準備基金・第9期の介護保険料）。監査委員の資料の記録があるのは、認定率と給付費の要素（毎年）と、保険料収納率・準備基金・第９期の介護保険料の要素。サービス別給付費単価の設定と地域支援事業費の推計には、事項も記録も無い。項目は、見本で、kansa-r4-04 の項目1（事実（事項の指定なし）→ 給付費の事実 → 認定率の事実 → 認定率の要望）を、どちらの事項の所からも切らずに読めた
- 合っていない例：まだ無い
- 外れたと言える条件：(1) 枠組みの要素に対応づけられない事項が多い（介護では16の事項（論点）のうち、図に載るのは5〜6。残りは計画の施策の体系の側の事項（介護人材の確保・介護予防の取り組み・計画の指標など）。これが「多い」かは、見せて確かめる）。(2) ほかの題材（幼保・公共施設・地域のあり方）で、出典のある枠組みが見つからない。(3) 職員・議員に見せても、枠組みの表（「<枠組みの名前>と、資料の記載状況」）や「同じ項目の記載」が使われない。(4) 判定で、項目の境目（suji の値）の直しが、項目の数の2割を超える
- ほかの見立て：点の並び（ADR-31）と照合結果の「問われていない点」（LINK_SCHEMA §13.2）で足り、枠組みは要らない。項目は、やりとりの記録と同じ型の台帳（まとまりの鍵・行の番号・答えの関係）で持つほうがよい（点検の報告の形3）
- 確かめ方と時点：介護の画面を見せるとき（K6）。次の題材の形の確かめ（ADR-31 の5）で、出典のある枠組みを探す
- 深さ：見方（waku キー）・参照表（ref/waku.tsv・ref/shiryo.tsv）・列の有無（suji）・見せ方
- 外れたときの手間：(1)〜(3) なら小さい（枠組みの参照表と見方を使わなくするだけで、記録の行は直さない）。(4) なら中くらい（項目を新しい台帳に移す。(資料の id, suji, 引用の本文の中の位置) から機械で作れる）
- 経緯：2026-11-14 仮説（DESIGN.md ADR-37。下書き Fable 5.2、文書 Opus 5.5）。2026-11-14 言い方を改めた（枠 → 枠組み、筋 → 項目、点を置く → 事項（論点）を対応づける。DESIGN.md ADR-37 の経過。中身は変えていない）。2026-11-14 項目の境目の決め方を改めた（話題で切っていたのを、原典の段落の中で要望の文までを1つにする。DESIGN.md ADR-37 の経過、docs/chosa-kansa-bunsho-2026-11-14.md）。外れたと言える条件の (4)（項目の境目の直しの割合）は、記録の番号を付け直したあとに数えて、ここに書き足す
